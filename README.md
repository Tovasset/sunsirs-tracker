# SunSirs 원자재 트래커 — 대시보드

생이사(生意社, [SunSirs](https://www.sunsirs.com/kr/)) 중국 대종상품 현물가에서
화장품ODM·화학 원가에 직결되는 워치리스트를 **매일 추적**하는 정적 대시보드.

**🔗 라이브:** https://tovasset.github.io/sunsirs-tracker/

## 특징
- 서버 불필요 — 순수 정적(HTML + 인라인 SVG 차트, 외부 스크립트 의존성 없음)
- 카테고리: 화장품·퍼스널케어 / 상류 석유화학·원가 / 기초 무기·범용 / 에폭시·안정제
- 품목별 스파크라인·상세 차트, 정렬 표, 전체 유니버스 급등락, 환율(CNY)
- 데이터는 매일 자동 수집으로 축적 (`data.js`)

## 데이터
- 출처: SunSirs (sunsirs.com) · 가격 단위 **CNY(위안)** · 기준일은 보통 1일 지연
- 수집 스크립트·워치리스트·원본 데이터는 이 저장소에 포함하지 않습니다(대시보드 산출물만 공개).
